# speaker-helper — runtime requirements (mirrors pyproject [project.dependencies]).
#
# Core dependency contract:
# - The engine runs **in this process**. There is no server to start and no
#   port to configure, so there is no HTTP client here either; the weights are
#   fetched once by ``speaker-helper install-voice`` (stdlib ``urllib``).
# - Part of the AI Helpers ecosystem: logging via ``os-helper``, audio
#   slicing/concatenation via ``audio-helper`` (both on PyPI).
# - Audio crosses the backend boundary as WAV ``bytes``; soundfile/numpy decode
#   it to measure duration and to concatenate streaming chunks.
#
# Optional features (kokoro, server, stt, youtube, podcast, mic, eval) live
# behind pyproject extras, not here — this file is the *runtime* floor only.
#
#     pip install -r requirements.txt      # runtime only
#     pip install -e .                     # same, from the package metadata
